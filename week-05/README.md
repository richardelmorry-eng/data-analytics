# Week 5: Beginning Python

Lab exercises from the Week 5 workbook, done in Python 3 and VS Code.

## Exercise 1: Getting started

- Ex1A_hello.py: my first Python script
- Ex1B_variable_examples.py: creating and printing variables

## Exercise 2: Math with numbers

- Ex2A_tips.py: tip calculator using input() and f-strings
- Ex2A_MathScripts/: practice scripts that do math with numbers
- Ex2B_MoreMathScripts/: more math scripts, including a rentals calculation

## Exercise 3: Strings, conversions and collections

- Ex3A_conversion_tests.py: converting between data types
- Ex3A_string_cleaning.py: cleaning up strings
- Ex3B_SampleCollections/: working with collections (movie_list.py, candy_store.py, address_entry.py)

## Exercise 4A: If statements

- Ex4A_IfScripts/if_basics.py: if/else blocks that each build on the value of x from the block before
- Ex4A_IfScripts/pay_rules.py: gross pay with overtime paid at 1.5 times the regular rate

## Exercise 4B: Lookups and greetings

- Ex4B_MoreIfScripts/dept_converter.py: department code to department name using if/elif/else
- Ex4B_MoreIfScripts/dept_converter_v2.py: the same lookup rewritten with match/case
- Ex4B_MoreIfScripts/greeting.py: a greeting based on the hour of the day, plus a late-night message
- Ex4B_MoreIfScripts/complex_taxes.py: weekly pay, annual pay and tax withholding by filing status
- Ex4B_MoreIfScripts/min_max.py: the smallest and largest of three numbers
- Ex4B_MoreIfScripts/show_major.py: major code lookup that shows `<unknown>` for codes not in the table

## Exercise 4C: Loops

- Ex4C_LoopScripts/loop_love.py: a for loop over a list of words
- Ex4C_LoopScripts/savings_goal.py: a while loop that adds weekly savings until a goal is met
- Ex4C_LoopScripts/ranked_list.py: a numbered list with enumerate() that flags the top pick
- Ex4C_LoopScripts/sales_performance.py: unpacking tuples in a for loop and flagging top performers

## What I learned

- Storing values in variables and formatting output with f-strings
- Doing math and converting between data types
- Making decisions with if/elif/else and match/case
- Repeating work with for loops, while loops and enumerate()
- Testing a script with several different inputs, including edge cases
