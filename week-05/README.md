# Week 5: Beginning Python

This week I wrote my first Python scripts. I worked in VS Code and ran each script from the terminal. Each exercise has its own folder or file, named after the workbook exercise it came from.

## What's in this folder

- `Ex1A_hello.py` and `Ex1B_variable_examples.py`: my first script and practice with variables
- `Ex2A_tips.py` and `Ex2A_MathScripts/`: math with numbers, including a tip calculator that uses `input()` and f-strings
- `Ex2B_MoreMathScripts/`: more math scripts, including a rentals calculation
- `Ex3A_conversion_tests.py` and `Ex3A_string_cleaning.py`: converting between types and cleaning up strings
- `Ex3B_SampleCollections/`: lists, tuples, and dictionaries (`movie_list.py`, `candy_store.py`, `address_entry.py`)
- `Ex4A_IfScripts/`: if/else logic (`if_basics.py`, `pay_rules.py` for gross pay with overtime)
- `Ex4B_MoreIfScripts/`: if/elif/else and match/case
  - `dept_converter.py` and `dept_converter_v2.py`: department codes to names, first with if/elif/else and then with match/case
  - `greeting.py`: a greeting based on the hour of the day
  - `complex_taxes.py`: weekly pay, annual pay, and tax withholding by filing status
  - `min_max.py`: smallest and largest of three numbers
  - `show_major.py`: major code lookup with an `<unknown>` fallback
- `Ex4C_LoopScripts/`: for and while loops
  - `loop_love.py`: a for loop over a list of words
  - `savings_goal.py`: a while loop that saves toward a goal
  - `ranked_list.py`: a numbered list with `enumerate()`
  - `sales_performance.py`: unpacking tuples in a for loop

## What I learned

- Variables, math, and f-strings for formatting output
- Lists, tuples, and dictionaries
- Decision making with if/elif/else and match/case
- Repeating work with for loops, while loops, and `enumerate()`
- Testing a script with several different inputs, including edge cases

## Notes

- `dept_converter_v2.py` uses `match/case`, which needs Python 3.10 or newer. My Mac came with Python 3.9, so I installed Python 3.14 and selected it in VS Code.
- To run a script, use `python3 path/to/script.py` from the `week-05` folder.
