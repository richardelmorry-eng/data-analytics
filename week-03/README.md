# Week 3: SQL Queries, Joins and Subqueries

Lab exercises from the Week 3 workbook, done in MySQL Workbench on the Northwind database.

## Exercise 1: Querying a database

- 1B_query_practice.sql: basic queries on products, categories, suppliers and employees, using SELECT, WHERE and LIKE
- 1C_query_practice.sql: sorting with ORDER BY, counting distinct customers, grouping, and filtering employees by salary

## Exercise 2: Working with joins

- 2A_using_joins.sql: joining products, categories, suppliers, orders, shippers and order details to answer questions across tables

## Exercise 3: Aggregate functions and grouping

- 3A_aggregations.sql: MIN, MAX, AVG, SUM and COUNT with GROUP BY and HAVING, including a rounded average price and inventory value

## Exercise 4: Subqueries

- 4A_subqueries.sql: queries nested inside other queries to find the most and least expensive products, orders shipped by a carrier, and who sold and bought an order

## What I learned

- Filtering and sorting results with WHERE and ORDER BY
- Combining tables with JOIN, including a table with a space in its name
- Summarizing data with aggregate functions, GROUP BY and HAVING
- Using a subquery to feed one query's result into another
